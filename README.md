- A documented C command-line search tool and a small Unix-style shell (with external commands; a simple pipe is stretch).

- A clean GitHub portfolio README, repeatable build/test notes, and a short reflection.
- A Java and SQL refresher started for future software/bursary opportunities—not a claim of guaranteed graduate-programme acceptance.
